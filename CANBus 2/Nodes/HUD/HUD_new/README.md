# HUD New

This new HUD is originally built by NYP students [Shi En](https://github.com/shiennnn) and [Michi](https://github.com/michitanxiuting-max/). This utilises a [WaveShare ESP32-S3-Touch-LCD-7](http://www.waveshare.com/wiki/ESP32-S3-Touch-LCD-7) embedded LCD screen with ESP32-S3 controller. 

## Compilation Instructions

The main project (HUD_LVGL) is made with the Arduino IDE, and you will need to install all dependencies properly before compilation. Due to the use of LVGL, this is a surprisingly tricky endeavour as you need to adjust several options before it will compile correctly.

1. File Explorer -> Unzip the folders in `arduino_libraries.zip` into your Arduino installation's libraries directory
    - NOTE: the `arduino_libraries/ui` folder is a strange oddity of this project, as it uses SquareLine Studio's method of exporting. Essentially, the `ui` library isn't really a code library, but rather contains the entire user interface layout generated by SquareLine. This folder constantly changes whenever you change the UI in the project, and must be updated every time there's a UI change. 
    - NOTE: the `arduino_libraries/lv_conf.h` file is another very important file, as it allows you to customise the LVGL library's parameters, such as what it imports. If you ever see a missing font error during compilation, chances are that this file is not set up correctly. You can't just enable every single font as they will be too much for the tiny storage onboard the ESP32S3.
2. Arduino IDE -> Install the 3.1.3 version of the esp32 via the Board Manager. Instructions [here](https://docs.espressif.com/projects/arduino-esp32/en/latest/installing.html). Other versions might not work!
3. Arduino IDE -> Select the Board definition as "Waveshare ESP32-S3-Touch-LCD-7"
4. Arduino IDE -> Select Tools > Partition Scheme and choose "Custom"
5. Arduino IDE -> Select Tools > PSRAM and choose "Enable"
6. Arduino IDE -> Select Tools > Flash Size and choose "16MB"

## Slave button program

The slave button is an Arduino Nano mounted on the 2nd PCB, and it acts like an I2C I/O expander allowing the ESP32S3 to sense button inputs. This is necessary as the drive selector depends on this part of the device.
